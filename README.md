# Student Result Analyzer 🎓

Teacher enters Name & Marks manually -> Code auto-calculates everything!

## Features
- Auto Total, Percentage, Grade, Pass/Fail
- Top 3 Students & Failed List
- Saves to Excel

## Tech
Python, Pandas

## How to Run
1. Install: `pip install pandas openpyxl`
2. Run: `python student_result_analyzer.py`
3. Enter number of students, then Name & Marks manually
4. Get results + `Final_Results.xlsx`
