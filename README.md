# Student Result Analyzer

Python tool that converts 10 hours manual work into 5 minutes for 50+ students.

## What it does?
- Reads student marks from Excel/CSV
- Calculates Total, Percentage, Grade, Pass/Fail
- Finds Top 3 students
- Shows Failed students list
- Saves final results to Excel

## Tech Used
Python, Pandas, OpenPyXL

## How to Run?
pip install pandas openpyxl
python student_result_analyzer.py

## Result
Input: Marks of 50 students
Output: Final_Results.xlsx in 5 seconds
